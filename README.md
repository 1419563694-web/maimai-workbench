# 麦麦的工作台 · Maimai Workbench

> Ruby 的个人工作台 PWA · 11 个 Dimoo 美食主题页面 · iPhone 17 全屏适配

## 🌟 特性

- 🎨 **Dimoo 美食主题**：11 个手绘 Dimoo 角色，每个菜单配专属潮玩形象（汉堡/蛋糕/橙子/冰淇淋等）
- 🌊 **高级感 UI**：浅蓝 + 高级灰配色，白底护眼，圆角卡片
- 📱 **iPhone 17 适配**：safe-area-inset 全面屏，全屏 PWA，可添加到主屏幕
- 💾 **离线可用**：Service Worker 缓存所有资源
- 🎤 **语音朗读**：英语单词英式发音 + 中文鼓励语音
- 💾 **本地存储**：localStorage 持久化打卡/任务/饮食/收藏

## 📑 11 个页面

1. 🏠 **首页** — 日期问候 + 4项打卡 + 倒计时 + 鸡汤
2. 📋 **每日计划** — 任务增删 + 进度条 + 看板
3. 🍽️ **每日饮食** — 三餐记录 + 饮水打卡 + 健康食物
4. 💎 **提升自己** — 外在/内在/技能/财商/社交 5 大类
5. 📝 **考试计划** — 教师编/公务员双tab + PDF链接 + B站课程
6. 📖 **英语学习** — 考研词卡 + 英音朗读 + 统计
7. 🏃 **运动减肥** — 周计划 + 圆肩驼背 + O型腿矫正
8. 📚 **教师备课** — 教案/PPT/习题三合一
9. 🌷 **心灵鸡汤** — 50+ 名言警句 + 收藏功能
10. 📚 **书籍推荐** — 7 大分类 + 微信读书一键阅读
11. 💗 **变大胸** — 训练 + 食物 + 按摩手法

## 🛠️ 技术

- 纯 HTML/CSS/JS 单文件应用（~1000 行）
- 11 个手绘 PNG 角色（PIL 矢量绘制，透明底）
- PWA manifest + Service Worker
- 适配 iPhone 17 / 16 / 15 Pro Max

## 📲 添加到主屏幕

1. 用 Safari 打开部署链接
2. 点击底部分享按钮 → "添加到主屏幕"
3. 名称：麦麦的工作台
4. 完成后桌面出现汉堡 Dimoo 图标
