# Ruby的工作台 · Ruby Workbench

> Ruby 的个人工作台 PWA · 11 个模块 · Dimoo 美食主题 × 星星人 · iPhone 16 Pro 全屏适配

## 🌟 特性

- 🎨 **Dimoo 美食主题**：11 个手绘 Dimoo 角色，每个菜单配专属潮玩形象（汉堡/蛋糕/橙子/冰淇淋等），星星人穿插打气
- 🌊 **清新简约 UI**：浅蓝渐变背景 + 高级灰，白色圆角卡片，白底护眼，选中项蓝色高亮
- 📱 **iPhone 16 Pro 适配**：safe-area-inset 全面屏，全屏 PWA，可添加到主屏幕
- 💾 **离线可用**：Service Worker 缓存所有资源
- 🎤 **语音朗读**：英式发音跟练 + 中文鼓励语音 + 录音回放对比
- 💾 **本地存储**：localStorage 持久化打卡/任务/饮食/体重围度/收藏

## 📑 11 个模块

1. 🏠 **首页** — Hero 进度环 + 连续打卡 + TODAY 两列网格联动跳转（汉堡Dimoo）
2. 📋 **每日计划** — 3项固定待办(吃早餐/运动/23点前睡)+自定义 + 工作计划高中低优先级 + 周进度环形图 + 7天柱状图（蛋糕Dimoo）
3. 🍽️ **每日饮食** — 拍照记录 + 常见食物热量库计算 + 1500kcal 提醒（橙子Dimoo）
4. 💎 **提升自己** — 8 大类资讯与视频推荐
5. 📝 **考试计划** — 2027 教师编/考公时间表（2026最新）+ 可点开 PDF + 名师视频 + 刷题小程序
6. 📖 **英语学习** — 6级词汇 + 英音跟练(常速/慢速) + 录音回放，专治哑巴英语
7. 🏃 **运动减肥** — 有氧/力量/拉伸打卡 + 阿新跟练(比心/甩锅/死虫/剪刀脚/平板/保加利亚蹲) + 体重围度昨今对比 + 低脂食谱（冰淇淋Dimoo）
8. 📚 **教师备课** — 八上道法第一课 3 种课型 PPT（时政导入/活动探究/议题式）+ 最新时政素材
9. 🌷 **心灵鸡汤** — 职场/情绪/自我治愈，每天 3 条不重样
10. 📚 **书籍推荐** — 心理/情绪/恋爱/成长/职场/口才/朋友经营 7 大分类，微信读书直达
11. 💗 **变大胸** — 分析 + 详细跟练 + 饮食

## 🛠️ 技术

- 纯 HTML/CSS/JS 单文件应用（~1400 行）
- 11 个手绘 PNG 角色 + 星星人（PIL 绘制，透明底）
- PWA manifest + Service Worker v5
- 适配 iPhone 16 Pro / 17 / Android

## 📲 添加到主屏幕（iPhone）

1. 用 Safari 打开部署链接
2. 点击底部「分享」按钮 →「添加到主屏幕」
3. 名称：Ruby的工作台
4. 完成后桌面出现 Dimoo＋星星 图标，全屏运行无浏览器栏
